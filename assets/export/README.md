# Word export assets

`reference.docx` is generated by `scripts/generate-export-reference-docx.ts`.

`NotoSansSC-Regular.ttf` is a static weight-400 instance of the existing `public/fonts/noto-sans-sc/noto-sans-sc-400.woff2`, converted with FontTools. It covers 7,946 code points and permits embedding (`OS/2.fsType=0`). Its family is normalized to `Noto Sans SC`; regular text and synthesized bold use the same embedded font. The bundled web font's glyph coverage is preserved.

The font is distributed under `OFL-NotoSansSC.txt`. DOCX generation embeds an obfuscated TrueType copy using the `docx` library. Readers that ignore embedded fonts still need a compatible local Chinese font. Headless LibreOffice validation uses an isolated Fontconfig configuration that includes this directory; it does not install fonts globally.
