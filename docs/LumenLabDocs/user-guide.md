## LumenLab 是什么

LumenLab 是一个面向学习、研究与课程项目的 AI 工作台。核心工作方式是：

1. 按项目组织你的课件、论文、实验数据、代码和笔记；
2. 上传后系统自动解析、分块、索引，建立可检索的资料库；
3. 对话时 AI 基于你的真实资料回答，并在回答底部列出来源；
4. 有价值的回答可以保存为成果，一键导出 Markdown、DOCX 或 PDF。

你不需要自己申请或配置任何 AI 服务的 API Key，访问凭证由管理员统一配置下发。

## 注册与登录

1. 打开 LumenLab 网址，点击注册。
2. 填写邮箱，完成邮箱验证（输入邮件中的 6 位验证码，或点击邮件里的验证链接）。
3. 设置密码，完成注册后用邮箱和密码登录。

注意事项：

- 注册时不需要注册码，新用户自动关联默认凭证配置。
- 忘记密码可在登录页点击「忘记密码」，通过邮件链接自助重置。
- 如果拿到管理员发放的注册码，可在设置的「服务访问」页自行更换，更换后立即生效。

## 聊天

侧边栏的「聊天」是与 AI 对话的主入口。

### 模型选择

输入框上方可切换模型：

- DeepSeek V4 Flash（默认，速度快）
- DeepSeek V4 Pro（能力更强，可选深度推理模式）
- MiniMax M3（多模态对话，同时负责图片 OCR 与 PDF 解析）
- Qwen3.7-Plus（支持文本输出与图像/视频理解，账号具备百炼凭据时可见）

可选模型以实际界面显示为准。开启深度推理后回答更细致，但响应更慢、用量更多，适合复杂推理题。

### 提问与渲染

- 回答以流式方式逐字输出，支持 Markdown、数学公式（KaTeX）、Mermaid 图表和代码高亮的实时渲染。
- 当回答引用了项目文件、网页或 arXiv 论文时，消息底部会展示来源列表，方便核对出处。
- AI 对不确定的内容会标注「需补充」，请留意甄别。

### 联网检索

当任务需要最新资料或外部文献时，系统可能建议联网；联网状态下 AI 可以检索网页和 arXiv 论文，结果同样会带来源标注。

## 项目与资料

项目是 LumenLab 组织工作的基本单位，每个项目有独立的资料库、对话记录和配置。

### 创建项目

1. 侧边栏点击「项目」→「新建项目」。
2. 选择项目类型：
   - 实验：实验报告、代码调试、计算过程
   - 复习：课件整理、知识点归纳、复习提纲
   - 编程：代码说明、算法分析、项目文档
   - 通用：日常笔记、自由问答
3. 可选配置：为项目设置独立的系统提示词和默认模型。

### 上传资料

- 支持格式：PDF、Office / WPS / iWork 文档、图片（PNG / JPEG / WebP）、文本（TXT / MD / CSV）和代码文件。
- 上传限制：单文件 50MB，单次最多 50 个文件，总大小 300MB。
- 解析方式：PDF 和图片由 MiniMax M3 原生解析（扫描件也可识别）；Office / WPS / iWork 文档由 MinerU 转为 Markdown 并保留文档内图片；文本和代码本地解析。
- 上传后稍等片刻，资料区会显示解析状态，完成后即可用于对话。
- 可选对解析结果做知识增强，提升检索质量。

### 在对话中引用资料

1. 进入项目工作台的项目聊天。
2. 在资料区勾选要引用的文件；不勾选时系统会按关键词和语义检索自动匹配。
3. 侧边栏的「资料图谱」按 topic / file / chunk 展示资料结构，可用于检查解析质量。

如果勾选的文件没有生效，先确认它已解析完成，并减少同时引用的文件数量。

## Skill 与 Agent 模式

### Skill 是什么

Skill 是针对特定学习场景的能力包。系统内置 13 个 Skill：

| 场景 | Skill | 典型用途 |
|------|-------|----------|
| 学术 | 论文阅读 | 论文速读、精读、多论文对比 |
| 学术 | 论文写作 | 论文初稿、报告结构、引用组织 |
| 学术 | 文献综述 | 研究现状梳理、方法对比 |
| 学术 | 图表规范 | 科学图表规范检查 |
| 学术 | 中文润色 | 去除 AI 痕迹、文字润色 |
| 考试 | 考点分析 | 考点抽取、考试范围整理 |
| 考试 | 复习教练 | 复习计划、速记卡、自测题 |
| 编程 | 代码阅读 | 代码解释、结构与调用路径分析 |
| 文档 | PDF / Word / PPT / Excel | 对应格式的阅读、起草与处理 |
| 学习 | 苏格拉底导师 | 追问式启发辅导 |

### 自动路由与手动切换

- Skill Router 会根据你的提问、选中文件和项目上下文自动激活合适的 Skill，无需手动选择。
- 你也可以在输入框工具栏的 Skill 选择器中手动切换或关闭 Skill；手动选择优先级最高。
- 如果没有自动激活 Skill，通常是任务太泛或缺少资料，可以手动指定，或先上传相关资料。

### Agent 工具调用与审批

激活 Skill 后，AI 可以调用工具完成多步任务（读文件、检索、保存成果等）。整个过程以时间线形式内联显示在对话中，包括工具开始、完成或失败的状态。

涉及有风险的操作时，会弹出审批卡片，展示受影响的资源、操作是否可逆和内容样本。你有三个选择：

- 仅本次允许：授权这一次操作，立即执行。
- 本会话同类允许：对低风险操作，本会话内同类操作不再重复询问。
- 拒绝：操作不会执行，落为拒绝终态。

风险分级说明：

- 读取类操作（读资料、检索、查文献）自动执行，不打断你。
- 写入类操作（保存成果、添加参考文献）首次询问。
- 删除资料、导出 DOCX 等操作每次都需要确认。

注意：允许或拒绝后工具会立即执行或终止，但 AI 不会自动续接之前的回答，请发送下一条消息让它基于最新状态继续。

## 学习闭环

从侧边栏的独立「学习」入口进入学习中心，围绕已有项目建立完整的学习路径。该入口由部署方通过学习闭环灰度开关控制，未开启时不显示。

使用流程：

1. 在学习中心选择一个已有项目，创建学习目标并确认学习范围（默认使用项目内全部可读资料）。
2. 系统生成带来源锚点的知识点地图，随后完成诊断练习。
3. 每次作答都会记录为独立证据；错题可以反复重做，答对后进入「已解决」区域仍可回看。
4. 在「复习」中处理到期的知识点，复习日历展示每日安排。
5. 在「档案」中按知识点查看掌握情况、作答证据和资料来源；如果认为模型判定的错因不准，可以追加人工修正标签，原始判定不会被覆盖。
6. 在「资料包」中基于最新知识点地图生成学习资料包：先确认大纲，再逐节生成内容，可编辑、重做单节，确认后可发布为成果。
7. 学习总览只突出一个「今日下一步」，并用分段条展示未开始、学习中、已掌握和到期复习的数量。

说明：

- 诊断与复习题在提交前只显示题面，答案与解析保留在服务端。
- 资料被重新解析或删除时，关联知识点会标记为待验证或不可用，已完成的学习历史会保留。

## 成果库与导出

对话中有长期价值的回答，可以保存为成果（Artifact）：

1. 点击回答下方的「保存为成果」。
2. 选择成果类型（实验报告、复习提纲、代码说明、思维导图等十余种）。
3. 在成果库中查看、复制，或导出为 Markdown、DOCX、PDF。

导出以 Markdown 为唯一正文源，三种格式内容一致；导出结果有缓存，重复下载即时返回。

## 文档转换工具

侧边栏「工具」入口提供独立的 PDF 转换能力，适合把整本课件、论文或扫描资料转成可编辑结构：

1. 上传 PDF，系统逐页解析，生成包含公式、表格和图片的 Markdown。
2. 在线预览完整渲染结果。
3. 下载 ZIP 包（含 Markdown、图片目录、样式 PDF 和 DOCX），或直接保存到某个项目作为资料。

提示：如果只是想让 AI 基于某份 PDF 回答问题，直接上传到项目即可，不必走转换工具；转换工具适合需要完整可编辑文档的场景。

## 账号与设置

- 侧边栏账户菜单可打开「设置」，包含：服务访问（查看 Alpha 访问状态、更换注册码）、用量统计（token 与成本）、个性化（AI 画像输入与生成提示词）、账号安全（修改密码）和外观（主题）。
- 昵称修改和头像裁切上传在账户菜单的「个人资料」弹窗中完成。
- 部署方开启用户级凭据（`USER_API_KEYS_ENABLED=1`）时，可通过 `POST /api/user/api-keys` 维护自己的 API Key。
- 界面遵循无障碍设计：支持键盘导航、可见焦点，并尊重系统的「减少动态效果」偏好。

## 使用小贴士

- 想让回答更「有据可依」：先建项目、传资料，再在项目内提问，比裸聊效果好得多。
- 想让回答更深入：开深度推理模式，或切换到 V4 Pro。
- 想让 AI 按你的方式工作：为项目设置系统提示词，例如「回答一律先给结论，再展开推导」。
- 处理扫描件：PDF 和图片直接上传即可，系统自带 OCR，无需先转文字。
- 重要成果及时保存到成果库，对话记录变长后查找旧回答不如直接查成果。
