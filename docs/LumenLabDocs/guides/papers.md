## 功能可用范围

论文排版是受服务端开关控制的功能。只有服务端把 `PAPER_FORMATTING_ENABLED` 设为 `true`（同时 `AGENT_DURABLE_EXECUTION_ENABLED` 也为 `true`）时才接受提交；未开启时提交会返回错误「后台排版暂未开放。」。自托管环境如果看不到效果，请先确认这两个变量。

历史论文工作区 `/papers/[id]` 的只读浏览不依赖该开关，但其中的编辑入口已经下线。

## 什么是论文排版

论文排版把「写作」与「格式」分开：你提供已经写好的 DOCX 或 Markdown 原稿，系统按学校模板完成章节识别、LaTeX 渲染与 PDF 编译。

入口在侧边栏的 **论文**，对应 `/papers` 页面，标题为 **论文排版**。页面顶部有两个入口：**上传原稿开始排版** 与 **模板库**。

系统的处理原则：

- 原稿始终保留，可以随时下载。
- 论文信息（题目、作者、学校等）只写入模板封面与页眉，不参与正文改写。
- 正文有独立的保真校验，结构识别只能改变章节角色，不能改动、增删或重排正文。

## 选择学校模板

**模板库** 展示 Registry 中的学校、学位、年份、来源与维护状态，可按学校或学位层级搜索，并按格式、维护状态、推荐等级筛选；有样例的模板提供 **查看实际样例**。

提交页只允许使用通过当前快照隔离编译验证的模板：

- 每个模板变体显示 **可提交** 或具体原因；暂不可用的变体会保留显示，方便你确认格式是否受支持。
- 顶部统计显示「记录 N · LaTeX N · 已验证 N · 可提交 N」。
- 可用的变体可以直接打开 **样例 PDF**。

## 提交一次排版任务

点击 **上传原稿开始排版** 进入 `/papers/typesetting`，按三步填写：

1. **1 · 选择学校与模板**：搜索学校名称，展开模板记录，在可提交的变体中选择。
2. **2 · 填写论文信息**：**论文题目** 与 **作者（多人用顿号分隔）** 必填（标记为 `*`）；按模板要求还会出现 **学校名称**、**学院**、**专业**、**学号**、**指导教师**、**学位类型**、**日期**。作者可用顿号、逗号或分号分隔，最多 10 位。
3. **3 · 上传原稿**：支持 DOCX 与 Markdown（`.docx`、`.md`、`.markdown`），单个文件最大 20 MB。旧版 `.doc` 请先在 Word 中另存为 `.docx`；Markdown 中的图片需要是可访问的公共链接。

点击 **提交后台排版** 后跳转到任务详情页 `/papers/formatting/[id]`。提交后可以离开页面，进度会通过站内通知提醒。

## 处理流程与状态

任务状态依次为：

| 状态 | 含义 |
|---|---|
| `queued` | 排队中 |
| `importing` | 读取原稿 |
| `mapping` | 识别章节结构 |
| `needs_input` | 等待结构确认 |
| `rendering` | 应用学校模板 |
| `compiling` | 生成 PDF |
| `validating` | 检查排版结果 |
| `completed` | 排版完成 |
| `failed` | 排版失败 |
| `cancelled` | 已取消 |

`mapping` 阶段会显示 **已完成 N / M 组结构识别** 与进度条；每组识别只把块的短结构描述交给模型，正文不会整篇外发。

编译在隔离的 Linux 沙箱中执行，服务端需要 `PAPER_COMPILE_LINUX_SANDBOX=true`、Linux 平台并以非 root 运行，否则排版任务不会进入编译。编译完成后系统会校验 PDF 的头尾标记、LaTeX 工程压缩包以及正文保真哈希，全部通过才把任务标记为 `completed`。

## 确认原稿结构

当导入或结构识别出现低置信度内容时，任务停在 `needs_input`，页面显示 **确认原稿结构** 卡片。

- 卡片逐块列出内容摘要、块类型、字数与 AI 判断的角色；置信度低于 0.8 的块标注「待确认」。
- 段落与标题可以改角色：**保持原样**、**标题**、**中文摘要**、**英文摘要**、**致谢**；选择「标题」后还可以选择 1—6 级标题。
- 图表、公式等受保护块显示「受保护，保持原样」，不能被改写。
- 核对完成后点击 **确认结构并开始排版**，任务才继续进入 `rendering`。

这一步只确认章节角色，模型不会改写正文。

## 预览与下载

任务进入 `completed` 后，详情页的 **排版结果** 区域直接渲染 PDF，显示「第 x / y 页」并提供上一页、下一页按钮。

页面顶部还提供：

- **PDF**：打开最终 PDF。
- **LaTeX 工程**：下载编译使用的 LaTeX 源码压缩包。
- **原稿**：下载你上传的原始文件。

## 取消与重试

- 进行中的任务可以点击 **取消排版**，任务变为 `cancelled`。
- 任务 **排版失败** 时可以点击 **重试排版**，最多到第 3 次。重试会保留已完成的导入与结构识别结果，只重放失败的模型批次。
- 如果模型计费版本在任务创建后更新，重试会被拒绝，需要重新上传原稿创建新任务。
- 每次重试都会在详情页显示「第 N 次提交」。

## 任务列表与历史

`/papers` 把任务分为 **进行中** 与 **历史任务** 两组，卡片显示当前阶段、第几次提交、更新时间与失败原因。

旧版论文工作区保留只读入口 `/papers/[id]`，包含 **只读大纲** 与 **历史 PDF**，页面注明「历史论文为只读，编辑入口已下线」。需要重新排版时，从那里点击 **上传原稿创建新的排版任务**，或直接回到 `/papers/typesetting`。应用内的论文编辑器、AI 改写与参考文献编辑已经移除，相关写入口不再提供。

## 常见问题

- 提交后提示「后台排版暂未开放。」：服务端未开启 `PAPER_FORMATTING_ENABLED`，或未开启 `AGENT_DURABLE_EXECUTION_ENABLED`，请联系管理员。
- 模板显示「暂不可用」：该变体尚未通过隔离编译验证，或缺少可用的 LaTeX 工程，可以先看样例 PDF 或改选其他变体。
- 上传 `.doc` 被拒绝：请先在 Word 中另存为 `.docx`，只改扩展名无效。
- 排版会改动我的正文吗：不会，结构识别只判断章节角色，正文另有保真校验。
- 提交后能关掉浏览器吗：可以，任务在后台推进，站内通知会提醒你确认结构或查看结果。
- 任务失败后原稿还在吗：在，原稿与已完成的结构识别结果都会保留，可以直接重试。
