# Separate mastery state from review state

Knowledge Points will carry an evidence-derived Mastery State of new, learning, or mastered independently from a Review State of unscheduled, scheduled, or due, so mastered knowledge can still return for spaced review without being relabeled as unmastered. The product may show an approximate progress ring or segmented bar derived from these states, with due work displayed separately, but will not present the internal policy score as a precise mastery percentage or predicted grade.
