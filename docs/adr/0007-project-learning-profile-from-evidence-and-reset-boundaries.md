# Project learning profiles are evidence projections with explicit reset boundaries

LumenLab keeps Practice Attempts and Evaluations append-only so a learner can inspect why a conclusion changed. A manual correction therefore creates new human evidence instead of rewriting model output, and “clear learning profile” creates a reset boundary that excludes older evidence from current mastery, weak-point, review, and recommendation projections. Casual chat and context summaries are never authoritative profile inputs, so an old summary cannot resurrect a corrected or cleared conclusion; deleting a Goal or Project remains the lifecycle operation for deleting the learning records it owns.
