# Revalidate only knowledge affected by material changes

Changes to Project Material will not reset an entire Learning Goal. Knowledge Points supported by unchanged material keep their learning state, while affected points retain historical evidence but enter a Content Freshness state of needs revalidation and stop counting as currently mastered until current-version evidence is collected; points with no remaining source become unsupported. This trades additional freshness tracking for preserving valid learner work without silently treating outdated evidence as current.
