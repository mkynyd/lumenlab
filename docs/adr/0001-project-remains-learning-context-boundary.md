# Project remains the learning context boundary

> 状态：已退役的历史学习设计。2026-10-01 起采用独立题集、错题本与日程，旧学习模型已移除。现行领域见 [CONTEXT](../../CONTEXT.md)，运行边界见[学习模块说明](../study-workspace.md)。

Learning capabilities will extend the existing Project with optional Learning Goals instead of introducing a separate Course or Lesson aggregate in P0. Project already defines the ownership and lifecycle boundary for material, conversations, and saved artifacts; keeping that boundary avoids two competing content containers and preserves existing authorization behavior, while accepting that future classroom or enrollment features may require this decision to be revisited.
