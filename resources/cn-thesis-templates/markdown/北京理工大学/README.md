# 北京理工大学 — Typst / 现代排版模板

> Typst 是新一代排版系统，比 LaTeX 更易上手、编译更快。

## 模板

- **Ri-Nai/BIT-Typst-Template** — [https://github.com/Ri-Nai/BIT-Typst-Template](https://github.com/Ri-Nai/BIT-Typst-Template)
  - 北京理工大学**本科毕业论文** Typst 模板（非官方），★21，最近维护 2025-11

## 说明

- 仅覆盖本科；硕士/博士建议使用 LaTeX 的 BIThesis（官方背书、CTAN 收录），见 `../latex/北京理工大学/README.md`
- Typst 生态中 BIT 模板较少，使用前请对照研究生院/教务部规范

## 与 LaTeX 的对比

| 维度 | LaTeX | Typst |
|------|-------|-------|
| 编译速度 | 慢（需多次）| 极快 |
| 学习曲线 | 陡 | 较缓 |
| 中文支持 | 成熟（CTeX/xeCJK）| 新（但已可用） |
| 生态/模板 | 极丰富 | 发展中 |
