# 北京大学 — Typst / 现代排版模板

> Typst 是新一代排版系统，比 LaTeX 更易上手、编译更快。

## 模板

- **pku-typst/pkuthss-typst** — [https://github.com/pku-typst/pkuthss-typst](https://github.com/pku-typst/pkuthss-typst)
  - 基于 Typst 的 PKU 学位论文模板

## 为什么选 Typst

- 编译速度极快（秒级 vs LaTeX 分钟级）
- 配置文件使用 TOML/JSON，无需宏包地狱
- 中文支持日趋完善（ctex 风格已支持）
- 主流在线编辑器：[Typst.app](https://typst.app)

## 与 LaTeX 的对比

| 维度 | LaTeX | Typst |
|------|-------|-------|
| 编译速度 | 慢（需多次）| 极快 |
| 学习曲线 | 陡 | 较缓 |
| 中文支持 | 成熟（CTeX/xeCJK）| 新（但已可用） |
| 生态/模板 | 极丰富 | 发展中 |
| 数学公式 | 顶级 | 优秀 |

## 配合 LaTeX 模板使用建议

如果学校没有 Typst 模板，仍然推荐 LaTeX 模板（参见 `../latex/北京大学/README.md`）。
