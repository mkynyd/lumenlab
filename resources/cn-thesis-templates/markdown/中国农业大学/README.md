# 中国农业大学 — Typst / 现代排版模板

> Typst 是新一代排版系统，比 LaTeX 更易上手、编译更快。

## 模板

- **JWangL5/CAU-ThesisTemplate-Typst** — [https://github.com/JWangL5/CAU-ThesisTemplate-Typst](https://github.com/JWangL5/CAU-ThesisTemplate-Typst)
  - 中国农业大学毕业论文 Typst 模板，kind 可配置本科/硕士/博士，★19，最近维护 2025-04，推荐度 B
- **universal-cau-thesis**（Typst Universe）— [https://typst.app/universe/package/universal-cau-thesis/](https://typst.app/universe/package/universal-cau-thesis/)
  - 推荐度 D（适用性与规范匹配未充分验证）

## 说明

- JWangL5 模板参考教务处模板要求编写，但为个人维护，README 自述"可能仍存在部分排版不合理"
- 官方 LaTeX 模板薄弱，Typst 是目前农大最活跃的排版方案之一

## 与 LaTeX 的对比

| 维度 | LaTeX | Typst |
|------|-------|-------|
| 编译速度 | 慢（需多次）| 极快 |
| 学习曲线 | 陡 | 较缓 |
| 中文支持 | 成熟（CTeX/xeCJK）| 新（但已可用） |
| 生态/模板 | 极丰富 | 发展中 |
