## 说明

- 目前仅覆盖本科层级；硕士/博士暂无公开 Typst 模板
- 使用前请与教务处当年通知核对格式

## 与 LaTeX 的对比

| 维度 | LaTeX | Typst |
|------|-------|-------|
| 编译速度 | 慢（需多次）| 极快 |
| 学习曲线 | 陡 | 较缓 |
| 中文支持 | 成熟（CTeX/xeCJK）| 新（但已可用） |
| 生态/模板 | 极丰富 | 发展中 |
