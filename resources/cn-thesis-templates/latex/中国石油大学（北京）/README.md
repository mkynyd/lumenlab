# 中国石油大学（北京）（China University of Petroleum-Beijing (CUPB)）— 学位论文模板索引

> 收录时间：2026-08

## 学校简介

教育部直属 211 / 双一流高校（非 985）；教务处提供本科撰写规范 docx，研究生院发布本硕博写作指南；公开 LaTeX 生态薄弱（多为华东校区模板）。
