# 复旦大学（Fudan University）— 学位论文模板索引

> 最后更新：2026-08

## 学校简介

C9、985。模板生态良好，LaTeX / Typst 皆有。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表
