# 北京师范大学-香港浸会大学联合国际学院（BNU-HKBU United International College (UIC)）— 学位论文模板索引

> 最后更新：2026-08
> 收录来源：GitHub / Overleaf / CTAN / 各校研究生院 / web_search

## 学校简介

2005 年成立于珠海的内地与香港合作办学高校，以本科为主；研究生院于 2023 年起招收研究型研究生（与浸大联合授予学位）。

## 通用规范要点

- 本科毕业环节为 FYP（Final Year Project），按教务处/学院规范执行
- 研究型研究生论文按 UIC 研究生院（Graduate School）论文规范，学位由浸大（HKBU）授予
- 参考文献采用学科惯例格式，中文文献可参考 GB/T 7714—2015

## 现成模板

- **LaTeX** [UICHCC/UIC-Research-Thesis-Template](https://github.com/UICHCC/UIC-Research-Thesis-Template) — 北师港浸大研究型研究生（Postgraduate Research）论文模板（非官方），基于 UIC 研究生院论文规范，MIT 许可，2024-01 更新，入口 thesistemplate.tex

> 推荐等级：C（社区模板，非官方，覆盖研究型研究生论文）


注意勿与"UIC"同名混淆：bitslab/uic-cs-thesis-template 是美国伊利诺伊大学芝加哥分校的模板，与珠海北师港浸大无关。
