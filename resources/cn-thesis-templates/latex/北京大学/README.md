# 北京大学（Peking University）— 学位论文模板索引

> 最后更新：2026-08
> 收录来源：GitHub / Overleaf / CTAN / 各校研究生院

## 学校简介

C9、985/211。学位论文有 Word 官方模板（2026 版），亦有 LaTeX 模板（pkuthss 系列）与新版 Typst 模板。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表

## 现成模板

- **LaTeX** [hauser-zhang/pku-doctoral-thesis](https://github.com/hauser-zhang/pku-doctoral-thesis) — 基于 pkuthss v1.9.4，对齐 2026 版 PKU Word 模板
- **Typst** [pku-typst/pkuthss-typst](https://github.com/pku-typst/pkuthss-typst) — PKU 学位论文 Typst 模板（新一代）
- **Word** [北京大学研究生院发布官方 Word 模板（2026 版，含工学院格式自审表）](https://www.coe.pku.edu.cn/service/biyedb/11191.html)
- [https://liiistem.cn/library/university-templates/pku-undergraduate-thesis](https://liiistem.cn/library/university-templates/pku-undergraduate-thesis) — 北京大学本科毕业论文 pkuthss 完整排版结构
