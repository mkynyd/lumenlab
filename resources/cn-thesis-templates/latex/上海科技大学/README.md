## 学校简介

上海科技大学是中国科学院与上海市共建的双一流高校（2022 年第二轮新增），以研究生培养为主，本、硕、博体系完整。学位论文以 LaTeX 为主流，社区模板 ShtThesis 收录于 CTAN。
