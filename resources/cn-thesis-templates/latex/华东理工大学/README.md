# 华东理工大学（East China University of Science and Technology (ECUST)）— 学位论文模板索引

> 最后更新：2026-08-23
> 收录来源：GitHub / 教务处（jwc.ecust.edu.cn）/ 研究生院（gschool.ecust.edu.cn）

## 学校简介

211、双一流。以化工为特色的理工科高校。社区存在本科 / 硕士 / 博士三套相互独立的 LaTeX 模板。

## 本科

### 官方规范
- 教务处《毕业论文格式规范及模板》— https://jwc.ecust.edu.cn/2023/1128/c3975a163108/page.htm
- 规范文件 PDF（华东理工大学文件）— http://jwc.ecust.edu.cn/_upload/article/files/75/9a/c411d4e6484ea84e7eb2684c043c/ec52a8bf-cc31-419e-9935-a20f5de54eb3.pdf
- 教务处文件 DOCX — https://jwc.ecust.edu.cn/_upload/article/files/88/0c/c5b7d8e1465ab3ec4a0106b1d015/bca7e8d6-5070-4a83-8efb-2991dd6b91ee.docx

### Word 模板
- 教务处"毕业论文格式规范及模板"页面提供官方格式文档（PDF/DOCX，见上）

### LaTeX
- [dagnaf/ecust-bachelor-thesis-template](https://github.com/dagnaf/ecust-bachelor-thesis-template) — 本科生毕业论文模板：依据《教务处本科生毕业论文格式规范（2006 年版）》，含开题报告、文献翻译、论文；XeLaTeX + ctex 编译

### Typst
- 未找到可靠公开模板

## 硕士

### 官方规范
- 研究生院《华东理工大学研究生学位论文撰写格式的统一要求》— https://gschool.ecust.edu.cn/2016/1207/c8276a58972/page.htm（相关规定栏目：https://gschool.ecust.edu.cn/12724/list.htm）

### LaTeX
- [blanche07/ecust-master-thesis-latex](https://github.com/blanche07/ecust-master-thesis-latex) — 硕士学位论文 LaTeX 模板：参照研究生院统一要求，正文小四宋体；XeLaTeX；参考文献用 biblatex 对齐 GB/T 7714—2015；推荐 Overleaf 编译

## 博士

### 官方规范
- 同硕士（研究生院统一要求）

### LaTeX
- [wjsong365/ECUST_Thesis_LaTeX](https://github.com/wjsong365/ECUST_Thesis_LaTeX) — 博士学位论文 LaTeX 模板：含图、表、算法示例；针对有 LaTeX 基础的用户

## 已知问题

- 本科官方规范页面对应 2006 年版格式，研究生统一要求页面发布于 2016 年；使用前请核对教务处 / 研究生院最新版本
- 另有 [lavandejoey/ECUSTThesisLatex](https://github.com/lavandejoey/ECUSTThesisLatex) 等社区仓库，适用学位未在 README 中明确
- GitHub API 限流，各仓库 commit 活跃度与 license 未逐一验证
