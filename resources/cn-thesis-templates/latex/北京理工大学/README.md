# 北京理工大学（Beijing Institute of Technology (BIT)）— 学位论文模板索引

> 收录时间：2026-08

## 学校简介

工业和信息化部直属 985 / 双一流高校；校内学生组织 BITNP 维护的 BIThesis 获教务部、研究生院、计算机学院认可背书，为事实标准模板。

## 本科毕业论文

- 《本科生毕业设计（论文）书写规范及打印装订要求》——公开网络有 DOC 转载（[book118](https://max.book118.com/html/2025/0209/8057123113007030.shtm)、[renrendoc](https://www.renrendoc.com/paper/495340688.html)），建议以学院/教务处发布页为准
- 「本科毕业设计论文格式检查系统」启用通知——计算机学院，[链接](https://cs.bit.edu.cn/rcpy/gzdt/e2f3c4867ac84a43a3b06488ad7fd193.htm)
#### Word 模板
- 未找到官方公开 Word 模板
#### LaTeX 模板
- [BITNP/BIThesis](https://github.com/BITNP/BIThesis)（CTAN 包 [bithesis](https://ctan.org/pkg/bithesis)）— 本硕博通用，★1161，最近维护 2026-07，编译 latexmk（XeLaTeX 系），文档类 bithesis，官方背书，推荐度 **A**
  - 在线文档 [bithesis.bitnp.net](https://bithesis.bitnp.net)（含 2026 更新说明）
- [Overleaf「Beijing Institute of Technology (BIT) 2024 version thesis template」](https://ja.overleaf.com/latex/templates/beijing-institute-of-technology-bit-2024-version-thesis-template/bxjqynnmbjtk) — 推荐度 C（维护情况未验证）

- [Ri-Nai/BIT-Typst-Template](https://github.com/Ri-Nai/BIT-Typst-Template) — 本科毕业论文 Typst 模板（非官方），★21，最近维护 2025-11，推荐度 B
