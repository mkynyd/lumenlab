# 上海交通大学（Shanghai Jiao Tong University (SJTU)）— 学位论文模板索引

> 最后更新：2026-08
> 收录来源：GitHub / Overleaf / CTAN / 各校研究生院

## 学校简介

C9、985。sjtug 组织维护多个 LaTeX 模板，含 SJTUThesis、sjtubeamer、sjtuthesis 等。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表

## 现成模板

- **LaTeX** [sjtug/SJTUThesis](https://github.com/sjtug/SJTUThesis) — 上海交大 LaTeX 论文模板
- **CTAN** [sjtutex](https://ctan.org/texarchive/macros/latex/contrib/sjtutex) — CTAN 收录的 SJTU 文档类集
- **官方说明** [上海交大研究生院论文写作模板说明](https://www.gs.sjtu.edu.cn/post/detail/Z3M2MjU=)
