# 中国社会科学院大学（University of Chinese Academy of Social Sciences (UCASS)）— 学位论文模板索引

> 最后更新：2026-08

## 学校简介

2017 年以中国社会科学院研究生院为基础组建，本硕博全层次，哲学社会科学特色。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表

## 现成模板

**LaTeX 模板：未发现**（截至 2026-08 检索，GitHub / Overleaf / CTAN 均无 中国社会科学院大学 学位论文专用 LaTeX 模板）。

> 推荐等级：**D**（无可用模板；如需 LaTeX 排版，建议基于 CTeX/xeCJK 自建或改用 Word/官方模板）


Overleaf 上的 "Thesis Template for UCASS"（https://de.overleaf.com/latex/templates/thesis-template-for-ucass/mzkhvshvcdgt ）实为**课程论文模板**（页面自述"社科大的课程论文模板"），非学位论文模板。
