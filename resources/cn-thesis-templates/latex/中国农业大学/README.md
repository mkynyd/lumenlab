# 中国农业大学（China Agricultural University (CAU)）— 学位论文模板索引

## 学校简介

教育部直属 985 / 双一流高校；官方发布学位论文格式书写规范，社区提供 Typst 模板（覆盖本硕博），LaTeX 模板来源较零散。
