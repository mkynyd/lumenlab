## 学校简介

985、双一流。原中国科学院研究生院，学位论文在中关村和各研究所提交。模板以 LaTeX 为主，社区版本最多。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表
