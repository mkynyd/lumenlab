# 西南交通大学（Southwest Jiaotong University (SWJTU)）— 学位论文模板索引

## 学校简介

211、双一流。轨道交通特色高校。社区 swjtuThesis 系列覆盖硕博（V2.0/V3.0 多版本），本科有新旧两个模板。

## 本科

### 官方规范
- 本科毕业设计（论文）撰写规范（学院下载）— https://dqxy.swjtu.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1464561310&wbfileid=8450D4CD05278FFEB41568C4B77FE306
- 本科毕业设计（论文）教学大纲及质量标准建设（PDF）— http://jwc.swjtu.edu.cn/download/rule/20230711104809281.pdf

### Word 模板
- 官方规范以网页/PDF 发布；未检索到独立 Word 模板包

### LaTeX
- [abwuge/SWJTU_Bachelor_Thesis](https://github.com/abwuge/SWJTU_Bachelor_Thesis) — 本科毕业论文 LaTeX 模板（2025 年更新版，旧仓库 swjtuhub/SWJTU_Thesis_Template 官方指路）
- [swjtuhub/SWJTU_Thesis_Template](https://github.com/swjtuhub/SWJTU_Thesis_Template) — 本科模板（按 2022 年毕业论文要求制作，作者已毕业、久未更新）

### LaTeX
- [Pungjay/swjtuThesis](https://github.com/Pungjay/swjtuThesis) — 硕/博学位论文 LaTeX 模板，严格按照《研究生学位论文撰写范式（2024 年 7 月编写）》编写
- [Sophie10001b/swjtuThesisV3.0](https://github.com/Sophie10001b/swjtuThesisV3.0) — swjtuThesis V3.0（支持硕士和博士；源自 Studio513/swjtuThesis 与 cshaowang V2.0 系列）
