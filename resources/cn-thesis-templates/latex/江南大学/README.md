# 江南大学（Jiangnan University）— 学位论文模板索引

> 最后更新：2026-08-23
> 收录来源：GitHub / 教务处（jwc.jiangnan.edu.cn）/ 研究生院（gs.jiangnan.edu.cn）

## 学校简介

211、双一流。以轻工、食品为特色的综合性大学。社区 LaTeX 模板 xen0n/JNUthesis 基于 NJUthesis 宏包制作，支持学士与硕士。

## 本科

### 官方规范
- 教务处《本科毕业设计(论文)撰写规范》和管理用表 — http://jwc.jiangnan.edu.cn/info/1065/4722.htm
- 关于做好 2024 届本科毕业设计（论文）工作的通知 — https://jwc.jiangnan.edu.cn/info/1014/7194.htm

### Word 模板
- 官方"撰写规范和管理用表"页面提供规范与管理用表（Word 表格式，见上）

### LaTeX
- [xen0n/JNUthesis](https://github.com/xen0n/JNUthesis) — 江南大学学位论文 LaTeX 宏包（基于 NJUthesis）：develop 分支支持学士（bachelor 选项，含毕业设计 bachelordesign 选项）与硕士（学术型 master / 专业型 prodegree，含盲审版选项）；master 分支 README 仅列学士
- 参考文章：LaTeX 工作室《江南大学学位论文 LaTeX 模板》— https://www.latexstudio.net/archives/3833.html
