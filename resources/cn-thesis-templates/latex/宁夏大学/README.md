## 学校简介

宁夏大学是国家 211 工程和双一流建设高校，设有研究生院，本、硕、博培养体系完整。其 LaTeX 模板 nxuthesis 已收录于 CTAN，是少数进入 CTAN 的地方 211 高校模板。
