# 西安交通大学（Xi'an Jiaotong University (XJTU)）— 学位论文模板索引

> 最后更新：2026-08
> 收录来源：GitHub / Overleaf / CTAN / 各校研究生院

## 学校简介

C9、985。LaTeX 与 Office 模板均有官方支持（2025 更新）。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表

## 现成模板

- **LaTeX** [Aetf/xjtuthesis](https://github.com/Aetf/xjtuthesis) — **主版本** XJTU LaTeX 模板
- **Office** [obster-y/XJTU-thesis-Office](https://github.com/obster-y/XJTU-thesis-Office) — 非官方 Office 模板（中英文）
- **Overleaf** [模板](https://ru.overleaf.com/latex/templates/xjtu-thesis/vzmthssprtrw) — Overleaf 模板
