## 学校简介

云南大学是国家 211 工程和双一流建设高校（双一流学科：民族学、生态学），设有研究生院，本、硕、博培养体系完整，均有博士点。研究生院与教务处分别发布学位论文写作规范与本科毕业论文格式要求。
