# 北京语言大学（Beijing Language and Culture University (BLCU)）— 学位论文模板索引

> 最后更新：2026-08

## 学校简介

1962 年建校，以汉语国际教育与语言学科为特色的"双一流"高校，本硕博全层次。

## 通用规范要点

- 本科生毕业论文（设计）按学校写作规范执行
- 研究生按《北京语言大学研究生学位论文编写规则》执行（研究生院 2014）
- 参考文献 GB/T 7714—2015（或学科惯例）
