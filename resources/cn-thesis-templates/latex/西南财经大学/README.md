## 学校简介

211、双一流。财经类高校。社区有本科 LaTeX 模板（sukanka 与 sierxue 两套）；研究生以官方 Word 规范为主。

## 本科

- 管理办法（DOCX，学院转载）— https://kj.swufe.edu.cn/__local/C/D6/E7/1A4CF3B4530DE01543DCEDB1B23_3EFE1A17_4697.docx?e=.docx

### Word 模板
- 官方规范为 DOCX/网页（见上）；未检索到独立发布的 Word 模板包

### LaTeX
- [sukanka/LaTeX-SWUFE-Bachelor-Thesis](https://github.com/sukanka/LaTeX-SWUFE-Bachelor-Thesis) — 本科毕业论文 LaTeX 模板（基于 HDU-Bachelor-Thesis 修改，仅支持 XeLaTeX）
