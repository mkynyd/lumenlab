## 学校简介

东北财经大学是财政部与辽宁省共建的财经类重点大学（非 211、非双一流），设有研究生院，本、硕、博培养体系完整（应用经济学等学科）。官方发布 Word 版《研究生学位论文格式要求》，但未见公开 LaTeX 模板。
