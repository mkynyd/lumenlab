# 河海大学（Hohai University (HHU)）— 学位论文模板索引

> 最后更新：2026-08-23
> 收录来源：GitHub / Overleaf / 本科毕业论文管理系统（bylw.hhu.edu.cn）/ 研究生院（gs.hhu.edu.cn）

## 学校简介

211、双一流。以水利为特色、工科为主的大学。社区有覆盖本/硕/博的 hhuthesis 与研究生 LaTeX 模板、本科 Typst 模板。

## 本科

### 官方规范
- 本科毕业设计（论文）规范格式参考（PDF，bylw.hhu.edu.cn）— http://bylw.hhu.edu.cn/UpLoadFile/83cd5f1169974a0db06d865c7ee11af4.pdf
- 《河海大学本科毕业设计（论文）基本规范（修订）》— https://wgyxy.hhu.edu.cn/2014/0410/c6638a108226/page.htm
- 本科毕业设计（论文）工作若干规定（修订）通知 — https://wgyxy.hhu.edu.cn/2014/0410/c6684a108330/page.htm

### Word 模板
- 官方规范以 PDF 发布（见上）；本科毕业论文管理系统中另有附件（如"附件2"规范参考）

### LaTeX
- [caowenhan/hhuthesis](https://github.com/caowenhan/hhuthesis) — 河海大学学位论文模板：可排版博士学位论文、硕士学位论文、（非）全日制专业学位硕士论文、本科毕业论文；对齐 2020.09.29 发布的《河海大学博士(硕士)学位论文编写格式规定》

### Typst
- [shaneworld/HHU-Thesis-Template](https://github.com/shaneworld/HHU-Thesis-Template) — 河海大学本科毕业设计（论文）报告 Typst 模板（工科，非官方）

## 已知问题

- hhuthesis 手册以仓库内 hhuthesis.pdf 发布，需自行下载阅读
- shaneworld Typst 模板与 Vitzron 模板均为非官方版本，作者声明"不保证满足最终论文提交要求"
- GitHub API 限流，各仓库 commit 活跃度未逐一验证
