## 学校简介

C9、985/211。工学/理学/管理学/人文等多学科。论文页边距、字号、参考文献严格遵守 GB/T 7713.1 与清华大学研究生院规定。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表
