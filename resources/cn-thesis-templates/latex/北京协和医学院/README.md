## 学校简介

1917 年创办的医学最高学府，临床医学八年制与清华大学联合培养，本硕博全层次。

## 通用规范要点

- 研究生学位论文按《北京协和医学院研究生学位论文写作规范》执行
- 参考文献 GB/T 7714—2015（顺序编码制）
- 临床医学八年制本科论文另按清华-协和联合培养规范
