## 学校简介

1999 年由北京轻工业学院等合并组建（办学历史可溯至 1950 年），本硕博全层次，食品与商科特色。

## 通用规范要点

- 研究生学位论文按《北京工商大学研究生学位论文写作规范》执行
- 参考文献 GB/T 7714—2015
