## 学校简介

1953 年建校（中央体育学院），体育学唯一"双一流"建设高校，本硕博全层次。

## 通用规范要点

- 研究生学位论文按《北京体育大学研究生学位论文写作规范（试行）》执行
- 参考文献 GB/T 7714—2015
- 论文形式规范性检测见研究生院通知
