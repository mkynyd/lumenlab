# 西湖大学（Westlake University）— 学位论文模板索引

> 最后更新：2026-08
> 收录来源：GitHub / Overleaf / CTAN / 各校研究生院 / web_search

## 学校简介

2018 年成立的新型研究型大学，以博士培养为主体，2022 年起招收本科生（西湖大学创新班）。学位论文 LaTeX 模板质量高。

## 通用规范要点

- 执行 GB/T 7713.1—2006《学位论文编写规则》
- 参考文献 GB/T 7714—2015（顺序编码制或著者-出版年制）
- 中英文摘要（关键词 3–8 个）
- 页码：前置罗马数字，正文阿拉伯数字
- 盲审版删除致谢、导师姓名、发表论文作者列表

## 现成模板

- **LaTeX** [Westlake-TUG/westlakethesis](https://github.com/Westlake-TUG/westlakethesis) — 西湖大学学位论文 LaTeX 模板（本科+博士论文，含 beamer 主题与 poster 模板），CTAN/TeX Live 收录，2026-06-18 发布，LPPL-1.3c

> 推荐等级：A（准官方，CTAN/TeX Live 收录，学校 TeX 用户组维护）


CTAN 收录页：https://www.ctan.org/pkg/westlakethesis ；文档：https://tug.org/texlive/devsrc/Master/texmf-dist/doc/latex/westlakethesis/westlakethesis.pdf 。注意 CTAN README 中旧仓库 myhsia/westlakethesis 已失效，当前仓库为 Westlake-TUG/westlakethesis。
