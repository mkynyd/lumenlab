# 上海中医药大学 — Word 论文模板索引

> Word 模板通常由学校研究生院在官网发布。

## 推荐获取渠道

1. 学校研究生院官网 → "学位工作" → "学位论文写作规范"
2. 校图书馆 → "论文提交" 页面
3. 各学院教务通知

## 已确认的官方规范与 Word 模板

- **《论文学术规范与写作指导》文件汇编（研究生院，2024-09）** — https://yjsy.shutcm.edu.cn/2024/0923/c1150a162167/page.htm

另有研究生学位论文写作指南 PDF（研究生院 _upload 附件）。

## 通用规范提示

- 使用 A4 页面，正文宋体小四/五号
- 1.5 倍行距，20 磅
- 参考文献按 GB/T 7714—2015 著录
- 多级标题统一使用 Word 内置样式

详见 `../latex/上海中医药大学/README.md` 中"现成模板"小节。
