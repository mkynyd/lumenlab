# 广州医科大学 — Word 论文模板索引

> Word 模板通常由学校研究生院在官网发布。

## 推荐获取渠道

1. 学校研究生院官网 → "学位工作" → "学位论文写作规范"
2. 校图书馆 → "论文提交" 页面
3. 各学院教务通知

## 已确认的官方规范与 Word 模板

- **研究生院学位论文答辩及学位申请通知** — https://yjs.gzhmu.edu.cn/info/1005/6943.htm
- **图书馆学位论文提交** — https://lib.gzhmu.edu.cn/lwtj.html

本科生撰写格式模板（第三方转载 doc）见 https://max.book118.com/html/2018/1202/8026024062001135.shtm

## 通用规范提示

- 使用 A4 页面，正文宋体小四/五号
- 1.5 倍行距，20 磅
- 参考文献按 GB/T 7714—2015 著录
- 多级标题统一使用 Word 内置样式

详见 `../latex/广州医科大学/README.md` 中"现成模板"小节。
