# 南京医科大学 — Word 论文模板索引

> Word 模板通常由学校研究生院在官网发布。

## 推荐获取渠道

1. 学校研究生院官网 → "学位工作" → "学位论文写作规范"
2. 校图书馆 → "论文提交" 页面
3. 各学院教务通知

## 已确认的官方规范与 Word 模板

- **学位论文撰写与印制要求（官方 docx，第三方转载，2024-01 版）** — https://www.renrendoc.com/paper/306528703.html

研究生院官网未直接检索到下载页；请以研究生院最新通知附件为准。

## 通用规范提示

- 使用 A4 页面，正文宋体小四/五号
- 1.5 倍行距，20 磅
- 参考文献按 GB/T 7714—2015 著录
- 多级标题统一使用 Word 内置样式

详见 `../latex/南京医科大学/README.md` 中"现成模板"小节。
