# 北京语言大学 — Word 论文模板索引

> Word 模板通常由学校研究生院在官网发布。

## 推荐获取渠道

1. 学校研究生院官网 → "学位工作" → "学位论文写作规范"
2. 校图书馆 → "论文提交" 页面
3. 各学院教务通知

## 已确认的官方规范与 Word 模板

- **本科毕业论文（设计）写作规范附件（官方域下载）** — http://psy.blcu.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1669781746
- **研究生学位论文编写规则（研究生院）** — https://yjsy.blcu.edu.cn/art/2014/3/26/art_13227_1122287.html

## 通用规范提示

- 使用 A4 页面，正文宋体小四/五号
- 1.5 倍行距，20 磅
- 参考文献按 GB/T 7714—2015 著录
- 多级标题统一使用 Word 内置样式
