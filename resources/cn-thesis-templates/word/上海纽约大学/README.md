# 上海纽约大学 — Word 论文模板索引

> Word 模板通常由学校研究生院在官网发布。

## 推荐获取渠道

1. 学校研究生院官网 → "学位工作" → "学位论文写作规范"
2. 校图书馆 → "论文提交" 页面
3. 各学院教务通知

## 已确认的官方规范与 Word 模板

- **无官方中文 Word 学位论文模板（按 NYU 体系提交）** — https://guides.nyu.edu/SocialWorkSH/writing-and-stylistics-guide

中文毕业论文模板不适用；请按学院 Capstone 要求与 NYU 规范撰写。

## 通用规范提示

- 使用 A4 页面，正文宋体小四/五号
- 1.5 倍行距，20 磅
- 参考文献按 GB/T 7714—2015 著录
- 多级标题统一使用 Word 内置样式

详见 `../latex/上海纽约大学/README.md` 中"现成模板"小节。
