# 武汉体育学院 — Word 论文模板索引

> Word 模板通常由学校研究生院在官网发布。

## 推荐获取渠道

1. 学校研究生院官网 → "学位工作" → "学位论文写作规范"
2. 校图书馆 → "论文提交" 页面
3. 各学院教务通知

## 已确认的官方规范与 Word 模板

- **本科毕业论文格式说明及范例（官方 doc，第三方转载，2025-02）** — https://www.renrendoc.com/paper/386359511.html

研究生学位论文撰写规范见研究生院通知附件。

## 通用规范提示

- 使用 A4 页面，正文宋体小四/五号
- 1.5 倍行距，20 磅
- 参考文献按 GB/T 7714—2015 著录
- 多级标题统一使用 Word 内置样式

详见 `../latex/武汉体育学院/README.md` 中"现成模板"小节。
