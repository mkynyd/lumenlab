# 中国大陆学位论文通用规范概述

> 本文件是 _raw/02_general_gb7713.md 的整理版本，列出来源中各高校研究生院发布的国家通用规范要点。

## 主要依据标准

| 标准号 | 名称 | 适用范围 |
|--------|------|----------|
| **GB/T 7713.1—2006** | 学位论文编写规则 | 全国所有高校（学位论文） |
| **GB/T 7714—2015** | 信息与文献 参考文献著录规则 | 各类参考文献引用 |
| **GB 3102—1993** | 量和单位 | 物理量、单位、符号 |
| **GB/T 15834—2011** | 标点符号用法 | 中英文混排标点 |
| **GB/T 15835—2011** | 出版物上数字用法 | 数字、年代书写 |
| **GB 3101—1993** | 有关量、单位和符号的一般原则 | 全文 |

## 通用论文结构（GB/T 7713.1）

学位论文一般由以下几部分组成，按顺序为：

1. **前置部分（Front Matter）**
   - 封面（Cover）
   - 扉页（Title page）
   - 独创性声明 / 使用授权声明（原创性声明）
   - 中文摘要（Abstract，中文关键词 3–8 个）
   - 英文摘要（Abstract，英文关键词 Keywords）
   - 目录（Table of Contents）
   - 插图清单 / 附表清单 / 符号说明（如有）

2. **主体部分（Main Body）**
   - 第 1 章 绪论 / 引言（Introduction）
   - 第 2 章 相关工作 / 理论基础（Background）
   - 第 3-? 章 核心内容（Methodology / Experiments / Results）
   - 最后一章 结论与展望（Conclusion）

3. **后置部分（Back Matter）**
   - 参考文献（References）— 强制使用 GB/T 7714
   - 致谢（Acknowledgements）
   - 附录（Appendix）
   - 攻读学位期间发表的论文与研究成果（Publication List）
   - 作者简介（作者简介 / Resume）

## 通用格式要点

- **页面**：A4（210mm × 297mm），上下边距一般 2.5cm，左右 3.0cm（部分高校为 2.5/2.5）
- **正文字体字号**：宋体 / Times New Roman 五号 (10.5pt)；一级标题黑体小三，二级黑体四号
- **行距**：1.5 倍 或固定值 20–24 磅
- **页眉页脚**：页眉五号宋体，页码五号 Times New Roman 居中或外侧
- **页码**：前置部分用罗马数字（I, II, III…），正文起用阿拉伯数字（1, 2, 3…）
- **图/表/公式编号**：分章依序连续，如"图 3-1"、"表 2-3"、"式 (4-5)"
- **参考文献**：顺序编码制（[1], [2]…）或著者-出版年制；2015 以后强制 GB/T 7714—2015

## 各地高校的具体执行

各高校在 GB/T 7713.1 基础上自行制定细则，常见差异：

- **论文长度**：硕士 3–5 万字，博士 5–10 万字（差异较大）
- **字体要求**：清华/北航/哈工大偏黑体标题；上交要求英文 Times New Roman
- **目录深度**：多数要求到 3 级标题
- **原创性声明页**：必须装订入纸质版并签名
- **盲审版**：删除致谢、导师姓名、发表论文作者列表
